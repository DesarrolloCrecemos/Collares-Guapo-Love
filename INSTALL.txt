# ⚡ Instalación Rápida

## 📦 Subir a WordPress

### PASO 1: Estructura de carpetas
Asegúrate de tener esta estructura exacta:

```
/wp-content/plugins/collar-configurator/
├── collar-configurator.php          
├── configurator-template-wawas.php        
├── collar-configurator-wawas.css      
├── collar-configurator-wawas.js       
└── assets/
    └── emojis/
        ├── lila/
        ├── azul/
        ├── verde/
        ├── amarillo/
        ├── naranja/
        ├── rojo/
        ├── rosa/
        └── blanco/
```

### PASO 2: Activar
1. WordPress admin → **Plugins**
2. Busca **"Configurador de Collar"**
3. Click **Activar**

### PASO 3: Usar
Pega en cualquier página/post: `[collar_configurador]`

---

## ✅ Verificar Instalación

Abre la consola del navegador (F12):
- [ ] No deberías ver errores 404 en las imágenes de emojis
- [ ] Las funciones changeCollarSize, changeCollarColor, loadEmojis deben estar disponibles
- [ ] Los emojis deben aparecer cuando cambias de color
- [ ] El layout debe mostrar imagen a la izquierda y panel a la derecha

---

## 🎨 Con Elementor

Widget "Shortcode" → Pega: `[collar_configurador]`

¡Listo! 🎉
